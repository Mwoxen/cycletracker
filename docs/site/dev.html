Udviklingsbuild (CloudKit)

Kun til de telefoner, der er registreret til ad hoc-builds. Åbn siden i Safari på telefonen og tryk på knappen. Appen erstatter den installerede version; dine data bliver på telefonen.

Installér Cycle Tracker (CloudKit dev)

Bagefter: Indstillinger → Automatisk deling → Start deling. Så findes posttypen cloudkit.share i Development-skemaet i CloudKit Dashboard og kan deployes til Production. Installér derefter TestFlight-versionen igen.
